- **The adoption guide now says what a fork pull request receives on each reusable-Action trigger** (#127). The automatic `pull_request` run is skipped. A manual `/ronda review` comment from an `OWNER`, `MEMBER`, or `COLLABORATOR` reviews the pull request with the base repository's token, and nothing from the fork is executed. The guide previously said only that fork pull requests "are not reviewed automatically". Documentation only; no behaviour change.
