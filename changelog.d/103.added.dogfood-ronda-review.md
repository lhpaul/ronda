  `ronda-review-dogfood.yml`, a caller of the reusable review workflow that
  runs on every non-draft pull request targeting `develop` and on the manual
  `/ronda review` comment. Its concurrency group is job-scoped, so unrelated PR

  `RONDA_MODEL_API_KEY` repository secret.
