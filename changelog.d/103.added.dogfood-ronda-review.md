- **Ronda now reviews this repository's own pull requests** (#103): added
  `ronda-review-dogfood.yml`, a caller of the reusable review workflow that
  runs on every non-draft pull request targeting `develop`, from its next push,
  reopen or ready-for-review event (a PR retargeted to `develop` after opening is
  not reviewed until then). Requires the
  `RONDA_MODEL_API_KEY` repository secret. The manual `/ronda review` comment
  trigger, and the job-level `concurrency` that serializes a manual pass with
  the automatic ones, were added separately in #109.
