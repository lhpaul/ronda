- **`/ronda review` comment trigger for this repository, and a corrected adopter
  snippet** (#109): `ronda-review-dogfood.yml` now also runs on `issue_comment`,
  so a collaborator's `/ronda review` comment starts a pass on the current head.
  `concurrency` moves from the workflow to the job, so a comment the `if:`
  rejects no longer enters a group at all and can neither cancel an in-flight
  pass nor displace a queued one; the accepted request forms share the pull
  request's group, so a manual pass waits behind an automatic one on the same
  head SHA instead of running alongside it and publishing a second check run.
  The adoption doc's caller snippet gets the same fix and now states that the
  caller job must not be named `Ronda review`, which made the pass skip itself
  and publish nothing. The pre-filter stays deliberately wider than Ronda's
  parser; the residual that leaves is documented in the snippet and in
  `docs/testing/ronda/dogfood-evidence-109.md`.
