- **Exclude generated and recorded-evidence files from review** (#134): review passes now apply a path-exclusion step before prompt construction — fixed defaults (lockfiles, generated/minified output, patchless/binary files) plus repository-configured globs (`RONDA_EXCLUDE_PATH_GLOBS` / `excludePathGlobs` / the reusable workflow's `exclude_path_globs` input) — so committed benchmark and evidence records no longer produce bogus findings. Every excluded file is named in the published review summary, and a pull request whose every file is excluded still publishes a summary stating that explicitly.
