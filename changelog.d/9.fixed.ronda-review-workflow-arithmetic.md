Fixed the reusable review workflow, which could not be parsed by GitHub Actions
and so failed at startup on every call. Two expressions used arithmetic
(`inputs.pass_timeout_minutes + 2` and `* 60000`), which the Actions expression
language does not support. A `setup` job now derives the outer job backstop and
the millisecond pass budget, keeping `pass_timeout_minutes` as the single public
input. Added an `actionlint` CI gate so an unparseable workflow cannot merge again.
