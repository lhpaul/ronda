- **Fix unparseable reusable review workflow** (#9): `.github/workflows/ronda-review.yml`
  used two GitHub Actions expressions with arithmetic operators
  (`inputs.pass_timeout_minutes + 2` and `* 60000`), which the Actions
  expression language does not support, so the workflow failed to parse and
  every call to it failed at startup with zero jobs. A new `setup` job now
  derives the outer job backstop and the millisecond pass budget in shell and
  publishes them as outputs, keeping `pass_timeout_minutes` as the single
  public input and the backstop strictly greater than the in-process budget
  for any accepted value. Added an `actionlint` CI gate so an unparseable
  workflow file cannot merge again.
